# TsukimiCode VPM Listing

This repository hosts the VPM (VRChat Package Manager) listing for TsukimiCode.

## Add to VCC / ALCOM

Add this repository URL in the VRChat Creator Companion (VCC) or ALCOM:

```
https://zz-roba.github.io/tsukimi-vpm/index.json
```

Then install **TsukimiCode Udon Tools** from the package list.

日本語: VCC または ALCOM に上記の URL を追加し、パッケージ一覧から TsukimiCode Udon Tools を導入します。
